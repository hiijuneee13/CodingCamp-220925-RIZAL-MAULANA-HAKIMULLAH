Deskripsi Proyek

Website ini adalah tugas RevoU berupa slicing desain menjadi kode HTML, CSS, dan JavaScript.
Website menampilkan halaman utama, profil perusahaan, dan formulir pesan interaktif dengan desain responsif.

Website terdiri dari 2 halaman utama:
	1.	index.html – Halaman utama dengan salam dinamis “Hai [Nama]”.
	2.	profil.html – Profil perusahaan yang berisi banner, tentang perusahaan, visi, dan misi.

Website menggunakan:
	•	HTML, CSS, dan JavaScript
	•	Animasi teks (typed effect sederhana dengan JS)
	•	Validasi form input pesan menggunakan JavaScript
	•	Desain responsif untuk mobile dan desktop

⸻

Fitur Utama
	•	Salam Dinamis: “Hai [Nama]” di halaman utama.
	•	Profil Perusahaan: Banner, tentang perusahaan, visi, dan misi.
	•	Formulir Pesan: Validasi input dan menampilkan hasil setelah submit.
	•	Desain Responsif: Tampilan menyesuaikan di semua perangkat.
	•	Navigasi: Profil dapat diakses melalui navbar.

Cara Menjalankan

- Menjalankan secara Lokal
	1.	Pastikan struktur folder tetap sama seperti di atas.
	2.	Buka html/index.html menggunakan browser modern (Chrome, Firefox, Edge).
	3.	Gunakan navbar untuk navigasi ke halaman Profil Kami.
	4.	Coba isi form Pesan Kami untuk melihat validasi dan hasil tampil di halaman.

- Menjalankan via GitHub Pages
	1.	Upload seluruh folder proyek ke repository GitHub.
	2.	Masuk ke Settings → Pages di repository GitHub.
	3.	Pilih branch (misalnya main) dan folder root (/) sebagai source.
	4.	Simpan pengaturan → GitHub akan memberikan link live website.
	5.	Buka link tersebut di browser untuk melihat website secara online.
